# 夢がかなう手帳

人生の大きな目標を決めて、それを少しずつ細かく分けながら、毎月見直していくための個人用プランナーです。
ブラウザで開くだけで動きます（インストール不要・単一HTMLファイル）。

**👉 [手帳をひらく](https://kq1kq1.github.io/yume_app/)**

---

## これは何をするものか

「やることリスト」ではありません。**一番大きな目標から順に細かく分けていき、日々の行動が何のためにあるのかを常に見えるようにする**ための道具です。

進捗率を追いかけることより、**自分が決めたことを何度も見返すこと**を目的に作っています。そのため、一覧画面でもタイトルだけでなく「どうなっていれば達成か」「なぜこれをやるのか」という本文がそのまま表示されます。

## 目標の階層

```
究極の目標              ← 人生をかけて実現したいこと（常に画面上部に表示）
 └ 6分野                ← 健康 / 心・精神 / 教養・知識 / プライベート・家庭 / 社会・仕事 / 経済
    └ 大目標            ← 10〜20年で成し遂げたいこと（戦略）
       └ 中目標         ← 数年で到達したい状態
          └ 単年度目標  ← 今年ここまで
             └ 四半期・月次目標   ← 3ヶ月〜1ヶ月の到達点
                └ やりたいこと・行動  ← 実際にやること（戦術）
```

分野を押すと中の大目標が出て、押すごとに一段ずつ深く降りていきます。
一番下の「やりたいこと」の画面には、**そこに至るまでの上位の目標がすべて表示される**ので、目の前の行動と究極の目標がつながったままになります。

## 画面

| 画面 | 役割 |
|---|---|
| **ホーム** | 究極の目標・人生時計（残り日数）・6分野のピラミッド・期限が近いもの |
| **今月の見直し** | ①期限を過ぎたもの ②今月・来月が期限 ③90日以上さわっていないもの を並べて、その場で処理。月次・年次のふりかえりも記入 |
| **目標ツリー** | 決めたこと全体を一望・折りたたみ表示 |
| **未来年表** | 何年に何を実現すると決めたかを俯瞰 |
| **習慣** | 「毎月やると決めたこと」「毎年やると決めたこと」のチェック表（記録は年ごとに保存） |
| **設定・保存** | 生年月日などの設定、バックアップ、同期の設定 |

## 使い方

1. **究極の目標を書く** — 人生をかけて実現したいこと。あとから何度でも直せます
2. **生年月日を入れる**（設定・保存）— 人生時計が動きます
3. **6分野に大目標を置く** — ピラミッドの分野を押して追加

あとは大目標 → 中目標 → … と、必要なところだけ掘り下げていきます。
途中の階層はとばして直接追加することもできます。

### 毎月やること

「今月の見直し」を開いて、上から順に片付けるだけです。
期限を過ぎたものは「達成にする」「期限を引き直す」「保留にする」をその場で選べます。
気づいたことは各目標の「ふりかえりを書く」に日付つきで残ります。

### 毎年やること

「今月の見直し」の一番下にある年次のふりかえり欄に、できたこと・できなかったこと・来年へ、を書きます。
そのうえで大目標から順に見直し、単年度目標を新しく引き直します。

## 複数の端末で同じデータを使う（同期）

データは通常、開いているブラウザの中だけに保存されます。
パソコンを買い替えたりスマホから見たりする場合は、GitHub の**非公開リポジトリ**にデータを自動保存する設定ができます。

### 準備

1. GitHub で**非公開 (Private)** のリポジトリを作る（作成時に「Add a README file」にチェック）
2. Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token
   - Repository access: **Only select repositories** → 1で作ったリポジトリだけ
   - Permissions → Repository permissions → **Contents: Read and write**
3. アプリの「設定・保存 → 同期」に、GitHubユーザー名・リポジトリ名・`data.json`・トークンを入力
4. 「設定を保存」→「接続をためす」→「今すぐ保存」

以後、書くたびに自動でGitHubへ保存されます。

### 新しい端末で続きから使う

同じ4項目を入力して「**GitHubから読み込む**」を押すだけです。

### 安全のための設計

- **トークンは端末ごとに別枠で保存され、バックアップJSONにもGitHubにも含まれません。** バックアップファイルを人に渡してもトークンは漏れません
- 他の端末で先に更新されていた場合、**黙って上書きせず**、両方の件数・更新時刻・端末名を並べて選択させます。選ばなかった側は自動でファイルに書き出されるため、どちらを選んでも消えません

## データの保管について

- 通常の保存先は**ブラウザの中**（localStorage）です。ブラウザのサイトデータを消すと保存内容も消えます
- 「設定・保存 → ファイルに書き出す」で、いつでも全データをJSONファイルとして取り出せます。**ときどき書き出しておくと安心です**
- 書き出したJSONは「読み込む」で完全に復元できます（目標・階層・ふりかえり・習慣の記録・設定のすべて）

## パソコンでオフラインで使う

このリポジトリを丸ごとダウンロードして、`手帳をひらく.bat` をダブルクリックすると、ローカルサーバー経由で開きます（Pythonが必要）。

> `index.html` を直接ダブルクリックしても開けますが、ブラウザによっては保存や同期が動きません。その場合は画面上部に警告が出ます。

⚠️ ランチャーのポート番号（8777）は変更しないでください。保存データはアドレスに紐づいているため、番号を変えると過去のデータが見えなくなります。

## 技術的な構成

- 単一のHTMLファイル（外部ライブラリなし・ビルド不要）
- 保存は localStorage、同期は GitHub Contents API
- ライト/ダークテーマ自動対応、印刷対応
